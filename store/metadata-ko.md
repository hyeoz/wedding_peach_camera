## 문구의 근거 (코드 확인 위치)

| 문구에서 주장한 것 | 확인한 코드 |
|---|---|
| 프레임 / 스티커 / 텍스트 3개 모드 | `src/data/library.ts` `OverlayMode`, `src/screens/HomeScreen.tsx` |
| 프레임·스티커는 내장 없이 사용자 등록형 | `src/data/library.ts` `getBuiltInItems()` — text 외에는 `[]` 반환 |
| 등록 항목이 앱 재실행 후에도 유지 | `src/storage/userLibrary.ts`, `src/context/UserLibraryContext.tsx` |
| 즐겨찾기 | `src/storage/favorites.ts`, `SessionContext.toggleFavorite` |
| 텍스트 템플릿 3종과 항목명 | `src/data/textTemplates.ts` — 데일리 체크(식단·운동·특이사항), 오늘 기분(기분·한줄일기), 심플 날짜 |
| 카드 머리글에 닉네임·날짜 자동 삽입 | `textTemplates.ts` `headerTemplate: '{nickname}님의 {date}'` |
| good / bad 선택과 자유 메모 | `textTemplates.ts` `type: 'choice' \| 'note'` |
| 촬영 또는 갤러리 선택 | `src/screens/SourceScreen.tsx`, `CaptureScreen.tsx`, `GalleryScreen.tsx` |
| 스티커 이동·확대·회전 | `src/components/PlacedItemView.tsx`, `SessionContext.updatePlacedItem` |
| 이모지에 따른 앱 색 변경 | `src/theme/palettes.ts` — 🎀 pink · 👾 purple · 💦 blue |
| 앨범 저장 / 시스템 공유 | `src/utils/media.ts` `saveToGallery()`, `shareImage()` |
| 서버 전송·계정·광고·분석 없음 | 네트워크 호출 코드 없음. 저장은 AsyncStorage와 앱 문서 디렉터리뿐 |
| iPhone + iPad 지원 | `app.json` `ios.supportsTablet: true`, `src/theme/responsive.ts` |
