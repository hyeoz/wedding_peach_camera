```

### 3-2. 핵심 판단 — Apple 기준으로 "수집"이 아닙니다

Apple의 App Privacy 정의에서 **"수집(Collect)"이란 데이터를 기기 밖으로 전송해 접근 가능한 형태로 보관하는 것**을 뜻합니다. 다음은 명시적으로 수집이 아닙니다.

> 데이터가 **기기에서만 처리되고 기기를 떠나지 않으면** 수집이 아닙니다.

웨피캠의 사진·닉네임·즐겨찾기·등록 항목은 **전부 기기 안에만 있고 어디로도 전송되지 않습니다.** 위 전수 검사에서 전송 경로가 아예 존재하지 않음을 확인했습니다.

### 3-3. ASC 설문 답안

**첫 화면 질문: "이 앱이 사용자로부터 데이터를 수집합니까?"**

```
▶ No, we do not collect data from this app
   (아니요, 이 앱에서 데이터를 수집하지 않습니다)
```

이 답을 선택하면 **데이터 유형·용도·추적 여부·앱 연결 여부를 묻는 후속 질문이 전부 나오지 않고 설문이 종료됩니다.**

참고로 후속 질문이 나왔다면 답은 이랬을 것입니다 (선택 불필요, 근거 기록용):

| 후속 항목 | 해당 답 | 이유 |
|---|---|---|
| 수집 데이터 유형 | 해당 없음 | 전송 자체가 없음 |
| 사용 목적 | 해당 없음 | — |
| 사용자 신원에 연결(Linked to You) | 해당 없음 | — |
| 추적에 사용(Used for Tracking) | **아니요** | ATT 미구현, 광고 식별자 미접근, 데이터 브로커 공유 없음 |

> **주의**: 나중에 크래시 리포팅·애널리틱스·광고를 하나라도 붙이면 이 답을 반드시 갱신해야 합니다. 특히 **Expo/EAS의 원격 업데이트(expo-updates)를 켜면** 기기 식별 정보가 서버로 가므로 재검토가 필요합니다. 현재는 `expo-updates`가 의존성에 없습니다.

> `expo-dev-client`가 의존성에 있지만 개발 빌드용 도구이며 데이터를 수집하지 않습니다. Release 구성에서는 동작하지 않습니다.

**질문: "이 앱에 서드파티 콘텐츠가 포함되어 있습니까?"**

```

`icon-candidate-shoujo.png` / `splash-shoujo.png` 의 캐릭터 일러스트가

- **직접 그린 것이거나 상업적 이용이 허용된 소재라면** → 위 답변대로 `No` 로 두면 됩니다.
