# App Store 스크린샷

App Store Connect > 앱 > 버전 > 미리보기 및 스크린샷 에 업로드하는 파일.

| 폴더 | 기기 | 요구 해상도 | 필수 |
|---|---|---|---|
| `iphone-6.9/` | iPhone 17/16 Pro Max | 1320 × 2868 | 예 |
| `ipad-13/` | iPad Pro 13-inch (M4) | 2064 × 2752 | 예 (`supportsTablet: true`) |

각 사이즈당 최소 1장, 최대 10장. 3~5장을 권장한다.

## 현재 상태

- [x] `01-home` — 홈 (모드 선택)
- [ ] `02-select` — 프레임/스티커 선택 그리드
- [ ] `03-edit` — 편집 화면 (스티커 배치)
- [ ] `04-text` — 텍스트 카드
- [ ] `05-result` — 완성 화면

`01-home` 외의 화면은 앱을 실제로 조작해야 도달할 수 있어 아직 비어 있다.
`../../scripts/screenshots.sh` 를 실행하면 시뮬레이터를 띄우고 상태바를 9:41 로
고정한 뒤, 화면을 맞출 때마다 Enter 로 캡처하고 해상도까지 검증해 준다.

촬영 전 준비:
- 편집 화면 촬영에는 프레임·스티커를 앱에서 먼저 등록해 두어야 한다
  (앱에 내장된 프레임·스티커가 없기 때문).
- 사진 앱이 비어 있으면 `--add-media <폴더>` 로 샘플 사진을 넣고 시작한다.
- 촬영 화면(카메라 미리보기)은 시뮬레이터에 카메라가 없어 캡처할 수 없다.
  필요하면 6.9" 실기기에서 찍으면 규격이 그대로 맞는다.
